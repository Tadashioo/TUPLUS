# TUPLUS multiidioma

Sitio estático de TUPLUS con cotizador y ocho idiomas.

- `frontend/`: páginas web, estilos, scripts y recursos del sitio. Punto de entrada: `frontend/index.html`.
- `backend/`: carpeta reservada; la implementación aún no existe.
- `docs/`: instrucciones y notas de verificación, separadas del código.

Consulta [las instrucciones](docs/INSTRUCCIONES.md) para abrir y revisar la versión local. No hay backend requerido para esta entrega.
